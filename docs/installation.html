Installation

Requirements

  • Node.js 18 or newer
  • A Minehut account with a server

One-time setup

Install the server globally, then install Chromium for the browser layer:

# 1. Install globally
npm install -g github:Tobralla/minehut-mcp

# 2. Install Chromium
minehut-mcp-setup
Works on any system. The package is plain Node.js plus Playwright. No native compilation, no platform-specific binaries.

Environment variables

Variable Purpose
MINEHUT_EMAIL / MINEHUT_PASSWORD Used by browser_login_panel when credentials are not passed per call
MINEHUT_TOKEN / MINEHUT_SESSION_ID Direct API session, captured automatically after browser login
MINEHUT_HEADLESS=0 Run the browser visibly. Recommended for the first login since Cloudflare is friendlier with a visible window

Running from source

git clone https://github.com/Tobralla/minehut-mcp.git
cd minehut-mcp
npm install
npm run dev

Build the production bundle with npm run build and start it with npm start.

Verify the install

Run the server on its own and ask your client to call minehut_help. It returns a short guide plus the current browser mode. A plain minehut_status call before logging in returns a clear message instead of a crash.
