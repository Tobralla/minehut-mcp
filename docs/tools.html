Tool reference

19 tools in total. The API layer needs a captured session (see authentication), the browser layer needs Chromium (minehut-mcp-setup).

⚡ API tools

ToolArgumentsDescription
minehut_status server Status, player count, RAM, MOTD, version and plugin list for a server. Accepts name or id.
minehut_servers none Lists every server on the logged-in account with live status.
minehut_start server Powers on the server service.
minehut_stop server Saves and powers off the server.
minehut_restart server Stops, waits briefly, then starts again.
minehut_command server, command Sends a console command with operator privileges, e.g. say hello, give Inxx diamond 64, time set day.
minehut_logs server, lines Returns the most recent console output, capped at 500 lines.
minehut_upgrade_ram server, ram Changes the RAM allocation in GB. The server may restart. Plan limits apply.

🖥️ Browser tools

ToolArgumentsDescription
browser_open url Opens a page in the controlled browser and returns the title, current URL and first part of the visible text so the AI can understand the page.
browser_login_panel email, password Logs into the dashboard in the browser and captures the API session automatically. Falls back to MINEHUT_EMAIL / MINEHUT_PASSWORD when arguments are missing.
browser_wait_manual seconds Waits while a human finishes a Cloudflare challenge, 2FA or password manager in the visible browser, then captures the session.
browser_click selector Clicks the first visible element matching a CSS selector.
browser_type selector, text, press_enter Types text into an element, optionally pressing Enter afterwards.
browser_press key Sends a keyboard key such as Enter, Escape, Tab or F5.
browser_text selector, max_chars Reads visible text of an element, or the whole page when no selector is given.
browser_screenshot selector, full_page Takes a screenshot of the page or one element and returns it as an image the AI can see, plus the file path.
browser_evaluate js Runs a JavaScript expression in the dashboard page and returns the result. Useful for React state, advanced clicks or custom automation.
browser_close none Closes the browser and releases resources.

🧭 Guidance tool

ToolDescription
minehut_help Returns an in-server guide with the recommended first-time flow and a hint about the current browser mode.
Server names vs ids. All minehut_* tools accept either the server name or its 24-character id. Names are looked up with ?byName=true; exact 24-character values are treated as ids.
