Client setup

Register the server with your AI tool of choice. Every config below launches the same npx -y github:Tobralla/minehut-mcp binary.

Claude Code

claude mcp add minehut-mcp \
  --env MINEHUT_EMAIL=you@example.com \
  --env MINEHUT_PASSWORD='your password' \
  -- npx -y github:Tobralla/minehut-mcp

Codex (OpenAI)

codex mcp add minehut-mcp \
  --env MINEHUT_EMAIL=you@example.com \
  --env MINEHUT_PASSWORD='your password' \
  -- npx -y github:Tobralla/minehut-mcp

opencode

Add to opencode.json in your project, or to ~/.config/opencode/opencode.json to make it available everywhere:

{
  "mcp": {
    "minehut": {
      "type": "local",
      "command": ["npx", "-y", "github:Tobralla/minehut-mcp"],
      "enabled": true,
      "environment": {
        "MINEHUT_EMAIL": "you@example.com",
        "MINEHUT_PASSWORD": "your password"
      }
    }
  }
}

Cursor

Create .cursor/mcp.json in your project, or use Settings → MCP:

{
  "mcpServers": {
    "minehut": {
      "command": "npx",
      "args": ["-y", "github:Tobralla/minehut-mcp"],
      "env": {
        "MINEHUT_EMAIL": "you@example.com",
        "MINEHUT_PASSWORD": "your password"
      }
    }
  }
}

Hermes

Add to hermes.toml (or config.toml):

[mcp.servers.minehut]
command = "npx"
args = ["-y", "github:Tobralla/minehut-mcp"]
env = { MINEHUT_EMAIL = "you@example.com", MINEHUT_PASSWORD = "your password" }
No credentials needed to start. Every config works without the environment variables. Call browser_login_panel after startup and pass the credentials directly in the conversation. The session is then captured and stored locally.

Other MCP clients

Any client that supports stdio MCP servers works. Point it at:

command: "npx"
args: ["-y", "github:Tobralla/minehut-mcp"]

For clients that need a local package, use the global install from the installation guide and set command to minehut-mcp.
