Minehut MCP

A Model Context Protocol server that lets any AI agent fully manage your Minehut Minecraft server. Used by Claude Code, Codex, opencode, Cursor, Hermes and every other MCP client.

MCP server Node.js 18+ Playwright MIT

Two layers, one install

Layer Tools What the AI can do
🖥️ Browser automation browser_open, browser_click, browser_type, browser_press, browser_text, browser_screenshot, browser_evaluate, browser_login_panel, browser_wait_manual Drive the real Minehut dashboard like a human. Handles Cloudflare, the login form and every UI feature: plugins, players, worlds, files, billing, skins. This is the do-everything layer.
⚡ Minehut API minehut_servers, minehut_status, minehut_start, minehut_stop, minehut_restart, minehut_command, minehut_logs, minehut_upgrade_ram Fast scriptable control. Start and stop servers, send console commands, read logs, check players.
